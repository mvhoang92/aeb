# Paper v5.2 — Camera-Gated AEB Brake-Permission Study (submission draft)

## Status

Submission draft that supersedes the v5.1 draft (`paper/paper_v5_1/` is kept
unchanged as the reference draft). The scientific campaign is still the frozen
v4 CUDA campaign; v5-derived severity/statistics are reused, and the only new
numbers (exact paired McNemar p-values) and figures are produced by committed
scripts from frozen evidence. No CARLA run was added, removed or retuned.
`paper/paper_v5/` remains the latest *frozen* (tagged) manuscript; v5.2 has
no tag yet (the author decides).

## Positioning

A controlled empirical comparison of three late brake-permission policies
(radar-only; hard car-camera gate; camera gate with radar emergency fallback)
in one shared CARLA sensor-to-brake pipeline. It does not claim a new fusion
detector, calibrated probabilistic tracker, road-population prevalence,
real-time ECU performance, vehicle validation, Euro NCAP/UN R152/ISO
compliance or functional-safety/SOTIF certification.

## Rebuild and validate

```bash
cd paper/paper_v5_2
./build.sh            # needs pdflatex, xelatex, bibtex, pdfinfo
cd ../..
../venv/bin/python scripts/analysis/analyze_v52_paired_tests.py   # McNemar CSV/JSON
../venv/bin/python scripts/analysis/plot_v52_figures.py           # Figs. 1-2
../venv/bin/python scripts/validate_v52_manuscript_claims.py
../venv/bin/python -m unittest tests.test_v52_analysis
```

`build.sh` fails on unresolved citations/references, missing glyphs,
font-shape substitution, overfull boxes wider than 1 pt, or an English PDF
that is not six pages. The validator checks every table against frozen CSV
files, recomputes the McNemar derivation, checks bilingual
equation/citation/figure/table parity, the derived-evidence checksums, the
`\artifactdoi` macro, and the English page budget (at most six).
